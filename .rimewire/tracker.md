not used as a proxy for missing implementation. Existing IDs and source links stay intact;

**Blocked** names a remaining data, device, provider, or CI gate.

[feature inventory](../docs/raidbots-feature-parity.md) retains requirement traceability.

blockers, decisions, and acceptance evidence through Rimewire. Journals stay checkout-local.

below record the actual implementation handoffs. `main` and `cloud` keep their existing roles; shared app
changes land on `main` and merge into `cloud`. New task branches use `dev/<id>-description`.

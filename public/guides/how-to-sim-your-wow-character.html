Getting started

How to sim your WoW character

Frostsim runs SimulationCraft in your browser. Use a fresh character import to estimate DPS for a particular fight, then compare changes using the same settings.

1. Export your current character

Install the SimulationCraft addon for retail WoW. Log in to the character you want to sim, equip the gear and select the talents you want to test, then type /simc in chat. Copy the full text from the export window.

An addon export captures your character as it is in game and can include bag items for gear comparisons. Export again after changing your equipment or talent loadout.

2. Import into Frostsim

Open Character, paste the text into the export field, and choose Import character. Review the imported gear, talents, and any warnings before continuing.

You can also look up a character by region, realm, and name on the Armory. That lookup uses the published equipment and active loadout; it cannot see your bags. Use the addon export when comparing items you already own.

3. Run a baseline with Quick Sim

Open Quick Sim. Set the fight style, duration, target count, buffs, and simulation precision for the scenario you want to model. Choose Run Quick Sim. The browser downloads the engine when it needs it, so the first run can take longer to start.

Live is the default engine channel. Check Help for the loaded game version and engine revision. Use PTR only when you intend to test the test-realm rules and a compatible engine is available.

4. Read the result before changing gear

The DPS result describes the simulated fight and action list. It is not a promised number for your next raid pull. Check the fight settings and the reported uncertainty alongside the headline DPS.

If two results are very close, increase precision before deciding that one is better. Keep the engine channel, revision, and fight settings the same when comparing setups.

5. Answer the next question

Use Top Gear for combinations of owned items, Compare for named gear or talent variants, or Droptimizer for potential drops. Read which simulation tool to use for more detail.
